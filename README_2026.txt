We include this reference so that our results can be easily reproduced.  The inputs for our specific system can be chosen and adjusted in-line within the Jupyter notebook, and the files that we read in are included in the folder </Input_Files>.----------------------------------------------------------------------------</Input_Files>This folder contains the FITS files and region file we used with our source reconstruction code in Eid & Keeton (2026; https://ui.adsabs.harvard.edu/abs/2025arXiv251111952E).  Contents are listed and described below:............................................................................<giant_arc_isolated.datamask.reg>This is a region file that contains the data mask we used on our isolated, cleaned giant arc.  ............................................................................<psf_814.fits><psf_606.fits><psf_435.fits>These are the effective point spread functions we calculated for each Hubble Frontier Fields filter.  ............................................................................<data_arc_cutout_F814W.fits><data_arc_cutout_F814W.fits><data_arc_cutout_F814W.fits>These are the masked, isolated, cleaned giant arc data files we constructed using the Hubble Frontier Fields science images.  ............................................................................<Abell370_OPT_alphax.fits><Abell370_OPT_alphay.fits><Abell370_OPT_kappa.fits><Abell370_OPT_gamma.fits>These are full-resolution, 3001x3001 pixel versions of the x deflection, y deflection, convergence, and shear maps (similar output as the Hubble Frontier Fields) from our locally optimized Abell 370 galaxy cluster mass model.  ............................................................................<mock_giant_arc_plain.fits>This is the PSF-free mock data we constructed by lensing a model source; we validated our source reconstruction methodology using this plain version as well as a version with added Gaussian noise in python.  ----------------------------------------------------------------------------</Output_Files/>This is a folder intended for output files defined in the .ipynb code: ............................................................................<UpdatedRGB.pdf>This is an example output, matching one of our published figures, from the Jupyter notebook included in this folder.  --------------------------------------------------------------------------------------------------------------------------------------------------------------
